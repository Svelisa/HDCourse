4. התקנת תוכנות בארגון

Software Installation

הלומדה מסבירה כיצד מתקינים תוכנות בארגון: התקנה ידנית ואוטומטית, תהליך ההפצה ב-SCCM, ממשק Software Center וקטלוג התוכנות

מטרות היחידה

  • הלומד יבחין בין התקנה ידנית להתקנה אוטומטית של תוכנות
  • הלומד יתאר את שלבי תהליך ההתקנה ב-SCCM
  • הלומד יסביר כיצד משתמשים מתקינים תוכנות דרך Software Center
  • הלומד יבחין בין הפצת תוכנה עבור משתמש להפצה עבור מחשב

פרקי היחידה

  1. 1 התקנת תוכנות במחשבשתי הדרכים להתקנת תוכנות בסביבה ארגונית
  2. 2 תהליך התקנה של SCCMשבעת השלבים בהתקנת תוכנה באמצעות SCCM
  3. 3 Software Centerהממשק שבו משתמשים מתקינים תוכנות מהקטלוג הארגוני
  4. 4 קטלוג תוכנותהפצת תוכנות עבור משתמש ועבור מחשב
  5. 5 בדיקת ידעשאלות לבדיקת ההבנה, עם משוב מיידי
