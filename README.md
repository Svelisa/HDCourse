# הכשרת נציגי HELPDESK – קורס מקוון

קורס בנוי מקבצי HTML, CSS ו-JavaScript רגילים, בלי תלות בספריות ובלי שלב בנייה.
פותחים את `index.html` בדפדפן – וזה עובד.

## מבנה הפרויקט

```
helpdesk-course/
├── index.html              עמוד הבית: כותרת, הקדמה וציר זמן היחידות
├── units/
│   ├── unit-1/index.html   עמוד לכל יחידה (תשע יחידות)
│   └── ...
├── css/
│   ├── base.css            צבעים (משתנים), איפוס וטיפוגרפיה
│   ├── layout.css          כותרת עליונה, תפריט צד, מבנה העמוד
│   └── components.css      כפתורים, כרטיסים, ציר זמן, אריחים, חלון פירוט
├── js/
│   ├── progress.js         שמירת התקדמות ופס ההתקדמות
│   ├── toc.js              תפריט הצד (נבנה מכותרות הפרקים)
│   └── tiles.js            אריחי תחומי אחריות וחלון הפירוט
└── images/                 תמונות (כרגע ריק – האייקונים מוגדרים ב-js/icons.js)
```

## איך עורכים תוכן

- **טקסט יחידה:** פותחים את קובץ היחידה ב-`units/` ועורכים את הטקסט בתוך התגיות.
- **פרק חדש ביחידה:** מוסיפים בתוך `<main>` בלוק כזה, והוא יופיע לבד בתפריט הצד:

  ```html
  <section class="card">
    <h2>שם הפרק</h2>
    <p>התוכן...</p>
  </section>
  ```

- **פירוט של תחום אחריות:** ביחידה 1, בכל אריח יש `<template>` עם `<p>`. מחליפים שם את הטקסט הזמני בפירוט (אפשר כמה פסקאות או רשימה).
- **אייקונים:** אייקוני SVG פנימיים בקובץ `js/icons.js` (אין תלות באינטרנט). בכל מקום כתוב `<i class="bi bi-שם">`, והסקריפט מחליף אותו באייקון בשם הזה. להוספת אייקון חדש מוסיפים שורה לרשימה בקובץ. כדי להשתמש בתמונה, שמים בתוך `<span class="ic">` תגית `img` עם `src` לקובץ ב-`images/`.
- **צבעים:** משנים את הערכים בראש `css/base.css`.
- **שם הקורס:** בכותרת העליונה (`<header>`) ובדף הבית.

## פרסום

מעלים את כל התיקייה לאירוח סטטי (למשל GitHub Pages: Settings ← Pages ← Deploy from a branch).
ההתקדמות של כל לומד נשמרת בדפדפן שלו (localStorage), ואינה נשלחת לשום שרת.

## מבנה מודולרי (יחידה 1 כדוגמה)

כל יחידה היא תיקייה: `units/unit-1/`
- `index.html` – עמוד פתיחה של היחידה (מטרות, רשימת פרקים, כפתור "התחלת היחידה")
- `chapter-1.html`, `chapter-2.html`, ... – עמוד נפרד לכל פרק, כולל פרק בדיקת ידע בסוף

בכל עמוד תפריט הצד מציג את כל פרקי היחידה, עם ✓ על פרקים שהושלמו. פרק מסומן כהושלם בכפתור "סימון כהושלם" (מפתח `data-lesson="יחידה-פרק"`), והיחידה נחשבת הושלמה כשכל פרקיה הושלמו. כל תשע היחידות בנויות כך (`units/unit-1/` עד `units/unit-9/`). רשימות הפרקים ביחידות 2–9 הן הצעה ראשונית ואפשר לשנות אותן.
